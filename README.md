## 📖 What are Data Types?

A **data type** defines what kind of value a variable can store. Different data types are used to store numbers, text, logical values, collections, and more.

## 🔹 Types of Data

### 1. Integer

Stores whole numbers.

```text
Example: 10, 25, -5, 100
```

### 2. Float

Stores numbers with decimal values.

```text
Example: 10.5, 3.14, -2.5
```

### 3. String

Stores text or a sequence of characters.

```text
Example: "Hello World"
```

### 4. Boolean

Stores one of two values:

```text
true
false
```

### 5. Character

Stores a single character.

```text
Example: 'A', 'B', '1'
```

### 6. Array

Stores multiple values in a single collection.

```text
Example: [10, 20, 30, 40]
```

### 7. Object

Stores data using key-value pairs.

```text
Example:
{
  name: "John",
  age: 25
}
```

### 8. Null

Represents the absence of a value.

```text
Example: null
```

## 📊 Quick Reference

| Data Type | Used For         | Example          |
| --------- | ---------------- | ---------------- |
| Integer   | Whole numbers    | `10`             |
| Float     | Decimal numbers  | `10.5`           |
| String    | Text             | `"Hello"`        |
| Boolean   | True/False       | `true`           |
| Character | Single character | `'A'`            |
| Array     | Multiple values  | `[1, 2, 3]`      |
| Object    | Key-value data   | `{name: "John"}` |
| Null      | No value         | `null`           |

## 🎯 Why Learn Data Types?

Understanding data types helps you:

* Write better programs
* Store data correctly
* Perform valid operations
* Understand variables
* Avoid common programming errors

## 🚀 Conclusion

Data types are one of the fundamental concepts of programming. Understanding them is important before moving on to variables, operators, functions, and other programming concepts.
